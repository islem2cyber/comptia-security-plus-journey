# Security Awareness

Security awareness is a critical part of an organization's cybersecurity program because users are frequently targeted by attacks that exploit human behavior.

Security awareness programs educate users about common threats, suspicious behavior, organizational security procedures, and the correct actions to take when an attack is suspected.

The goal is to build a security-conscious culture where users pause, verify unexpected requests, follow established procedures, and report suspicious activity.

## Learning Objectives

By the end of this lesson, you should be able to:

- Explain the importance of security awareness.
- Understand how human behavior affects cybersecurity.
- Recognize common indicators of social engineering and phishing.
- Understand the importance of verifying unexpected requests.
- Apply security awareness best practices.
- Understand the role of security policies and procedures.
- Explain the importance of incident reporting.
- Understand how security awareness works together with technical and physical controls.

## Why Security Awareness Matters

Attackers frequently target people rather than directly attacking technical systems.

Social engineering attacks can manipulate:

- Trust
- Authority
- Fear
- Curiosity
- Urgency

Users may be convinced to:

- Reveal sensitive information
- Click malicious links
- Open malicious attachments
- Transfer money
- Install malware
- Grant unauthorized access

Regular security awareness training helps users recognize these situations and respond appropriately.

## Core Principle

Users should not automatically trust unexpected requests.

Before taking action, they should:

1. **Stop** before acting immediately.
2. **Think** about whether the request is reasonable.
3. **Observe** for suspicious indicators.
4. **Proceed** only after verification.
