# Exam Reminders

### Phishing

- **Phishing** → General phishing
- **Spear phishing** → Targeted phishing
- **Whaling** → Executive/high-profile targets
- **Smishing** → SMS phishing

### Anomalous Behavior

- **Risky** → Increases security exposure
- **Unexpected** → Deviates from normal behavior
- **Unintentional** → Accidental mistake

### Awareness Framework

**Goals / Needs Assessment → Development → Delivery → Feedback → Monitoring**

### Training Effectiveness

Measure results using:

- Security incidents
- Phishing simulations
- Knowledge checks
- User behavior
- Participation and completion rates
- Feedback

### Core Principle

> Security awareness is a continuous process.

Training should be **relevant, practical, measurable, regularly updated, and continuously improved**.
