# Exam Reminders

### Guidelines vs Policies

**Guideline** → Flexible recommendation  
**Policy** → Formal and enforceable rule

### SDLC

**Development → Testing → Staging → Production**

### Important Standards

- ISO 27001 → ISMS
- ISO 27002 → Security controls and best practices
- ISO 27701 → Privacy
- ISO 27017 → Cloud security
- ISO 27018 → Cloud personal-data privacy
- NIST SP 800-53 → Security controls
- FIPS → U.S. federal IT/cybersecurity standards
- PCI-DSS → Payment card data

### Data Roles

**Owner** → Safeguards data and oversees proper use  
**Controller** → Defines data collection/processing policies  
**Processor** → Processes data according to the controller's instructions  
**Custodian** → Stores, encrypts, and backs up data  
**Steward** → Maintains data quality, metadata, and classification

### Governance

Effective governance requires:

**Policies + Standards + Procedures + Roles + Oversight + Continuous Monitoring**
