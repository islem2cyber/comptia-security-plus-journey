# Explain Common Threat Vectors and Attack Surfaces

Every cyber attack begins with an opportunity. Attackers exploit weaknesses in people, processes, technologies, or physical environments to gain unauthorized access to systems and data.

Understanding how attacks are delivered (threat vectors) and where vulnerabilities exist (attack surfaces) is essential for building effective security controls and reducing organizational risk.

This lesson introduces the most common threat vectors used by attackers, explains different types of attack surfaces, and explores practical strategies for minimizing exposure to cyber threats.

## Learning Objectives

By the end of this lesson, you should be able to:

- Define threat vectors and attack surfaces.
- Differentiate between various attack vectors.
- Identify common attack surfaces in modern environments.
- Understand how attackers exploit exposed systems.
- Explain methods used to reduce attack surfaces.
- Apply these concepts to real-world cybersecurity scenarios.
