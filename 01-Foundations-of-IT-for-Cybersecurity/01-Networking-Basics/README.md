# Networking Basics

## Introduction

Computer networking is one of the fundamental pillars of modern Information Technology and cybersecurity. Every digital service, from web browsing and email to cloud computing and online banking, relies on networks to exchange information between devices.

Understanding how networks operate is essential for security professionals because most cyberattacks target systems connected through a network. A solid foundation in networking enables security analysts to identify communication patterns, recognize abnormal behavior, and implement effective security controls.

This lesson introduces the core networking concepts required before studying network security, protocols, vulnerabilities, and defensive technologies covered throughout the CompTIA Security+ certification.

## Learning Objectives

After completing this lesson, you should be able to:

- Explain what a computer network is.
- Understand why networking is essential in modern computing.
- Differentiate between common network types.
- Identify the primary components of a network.
- Describe the purpose of the OSI Reference Model.
- Recognize the relationship between networking and cybersecurity.

## What Is a Computer Network?

A computer network is a collection of interconnected devices that communicate with one another to exchange data and share resources using standardized communication protocols.

These devices may include:

- Computers
- Servers
- Smartphones
- Tablets
- Printers
- Network appliances
- IoT devices

Networks allow users and systems to access shared resources such as files, applications, internet connectivity, and cloud services regardless of their physical location.

## Why Networking Matters

Networking enables organizations to efficiently share information, centralize resources, improve communication, and provide remote access to services.

From a cybersecurity perspective, understanding networking is critical because nearly every security event involves network communication. Firewalls, intrusion detection systems, VPNs, web applications, cloud platforms, and endpoint protection all depend on networking principles.

Without networking knowledge, it is difficult to understand how attacks propagate, how data travels between systems, or how security controls monitor and protect digital environments.

## Types of Networks

Computer networks are commonly categorized according to their geographic coverage.

### Local Area Network (LAN)

A LAN connects devices within a limited geographic area such as a home, office, school, or campus. It provides high-speed communication between nearby devices and is typically owned and managed by a single organization.

### Metropolitan Area Network (MAN)

A MAN connects multiple LANs across a city or metropolitan region. It provides connectivity over a larger area than a LAN while remaining smaller than a WAN.

### Wide Area Network (WAN)

A WAN connects devices and networks across large geographic distances, including countries and continents. The Internet is the world's largest WAN.

## Network Components

A computer network consists of multiple hardware and software components working together.

Common network components include:

- End devices (clients and servers)
- Network Interface Cards (NICs)
- Switches
- Routers
- Wireless Access Points
- Firewalls
- Communication media (copper cables, fiber optics, wireless signals)

Each component plays a specific role in enabling communication between devices.

## The OSI Reference Model

The Open Systems Interconnection (OSI) model is a conceptual framework that standardizes how devices communicate across a network.

It divides network communication into seven logical layers, allowing vendors and engineers to design interoperable networking technologies.

Understanding the OSI model is essential for troubleshooting networks, analyzing traffic, understanding communication protocols, and identifying security issues at different layers of communication.

The seven layers are:

1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application

Future lessons will examine each layer and the protocols associated with it in greater detail.

## Key Takeaways

- Computer networks enable devices to exchange data and share resources.
- Networking is a foundational skill for every cybersecurity professional.
- Networks can be classified as LAN, MAN, or WAN based on geographic scope.
- Communication relies on specialized network devices and standardized protocols.
- The OSI model provides a structured framework for understanding network communication and troubleshooting.
