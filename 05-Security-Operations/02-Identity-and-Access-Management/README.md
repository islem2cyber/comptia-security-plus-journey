# Identity and Access Management (IAM)

This lesson introduces the core concepts of Identity and Access Management (IAM), including how organizations provision user accounts, manage identities, authenticate users, and control access to enterprise resources.

Identity and Access Management is a critical component of enterprise security. It ensures that users receive the appropriate level of access based on their roles while protecting sensitive systems and data from unauthorized access.

## Learning Objectives

By the end of this lesson, you should be able to:

- Explain the purpose of Identity and Access Management (IAM).
- Understand the user account provisioning and deprovisioning processes.
- Describe the role of Active Directory and directory services.
- Explain how Kerberos and NTLM authenticate users.
- Understand federation, Single Sign-On (SSO), and identity interoperability.
- Identify common enterprise identity management technologies.
