# Use Data Sources to Support an Investigation

This lesson explores the various data sources that security professionals use during incident investigations. It explains how logs, network captures, endpoint artifacts, cloud records, threat intelligence, and other forensic evidence help analysts reconstruct events, identify malicious activity, determine the scope of an incident, and support effective response and recovery.

Understanding where security evidence originates and how to interpret it is a critical skill for security analysts, incident responders, and digital forensic investigators.

## Learning Objectives

By the end of this lesson, you should be able to:

- Identify common data sources used during security investigations.
- Explain the value of log analysis during incident response.
- Understand network and endpoint evidence collection.
- Recognize cloud-based and application data sources.
- Explain the role of threat intelligence in investigations.
- Correlate evidence from multiple systems to determine attack timelines.
- Understand best practices for collecting and preserving digital evidence.
