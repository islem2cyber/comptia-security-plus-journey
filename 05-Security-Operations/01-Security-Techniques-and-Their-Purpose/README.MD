# Apply Common Security Techniques to Computing Resources

This lesson introduces the essential security techniques used to protect computing resources in enterprise environments. It focuses on establishing secure baselines, hardening systems, securing wireless and mobile devices, and implementing practical controls that reduce the organization's attack surface.

These techniques help security professionals deploy consistent security configurations, protect endpoints, and maintain secure computing environments.

## Learning Objectives

By the end of this lesson, you should be able to:

- Explain the purpose of secure baselines.
- Understand system hardening techniques.
- Identify methods for securing wireless networks.
- Recognize best practices for mobile device security.
- Apply common security techniques to computing resources.

## Topics Covered

- Secure Baselines
- System Hardening
- Wireless Security
- Mobile Device Security
- Enterprise Security Best Practices
