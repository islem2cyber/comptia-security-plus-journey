# Social Engineering Tools

This lesson introduces the common tools and techniques used in social engineering attacks. These tools help attackers manipulate human behavior to obtain sensitive information, gain unauthorized access, or compromise systems.

Understanding these tools enables security professionals to recognize social engineering attempts, educate users, and implement effective defensive measures.

## Learning Objectives

By the end of this lesson, you should be able to:

- Identify common social engineering tools.
- Explain how attackers use these tools.
- Recognize indicators of social engineering attacks.
- Understand defensive strategies against social engineering.
- Apply security awareness best practices.

## Topics Covered

- Phishing Frameworks
- Credential Harvesting
- Email Spoofing
- Voice and SMS Attacks
- USB and Physical Attack Tools
- Defensive Best Practices
