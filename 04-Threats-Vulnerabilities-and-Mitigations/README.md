# Threats, Vulnerabilities, and Mitigations

This section explores the security threats, vulnerabilities, attack techniques, and defensive strategies covered in the CompTIA Security+ (SY0-701) certification.

The lessons explain how cyber threats target systems, applications, networks, and users, how vulnerabilities are discovered and exploited, and how security controls reduce risk. Practical examples and hands-on exercises reinforce the concepts through real-world scenarios.

## Learning Objectives

By completing this section, you will be able to:

- Identify common malware types and their characteristics.
- Recognize social engineering techniques and human-focused attacks.
- Understand application, network, and wireless attack methods.
- Explain common vulnerabilities and their impact.
- Perform basic vulnerability assessment activities.
- Apply security controls and mitigation strategies to reduce risk.
- Recognize indicators of compromise and attack behavior.

## Topics

- Malware
- Social Engineering
- Application Attacks
- Network Attacks
- Wireless Attacks
- Vulnerability Management
- Indicators of Compromise
- Security Mitigations
