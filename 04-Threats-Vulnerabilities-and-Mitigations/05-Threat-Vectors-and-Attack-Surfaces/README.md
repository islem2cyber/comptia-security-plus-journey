# Threat Vectors and Attack Surfaces

This lesson explains how attackers gain access to systems by exploiting various threat vectors and attack surfaces.

Understanding where attacks originate and which assets are exposed helps organizations reduce risk, strengthen defenses, and minimize opportunities for attackers.

## Learning Objectives

By the end of this lesson, you should be able to:

- Define a threat vector.
- Define an attack surface.
- Differentiate between common threat vectors and attack surfaces.
- Identify common methods attackers use to compromise systems.
- Explain how organizations reduce their attack surface.

## Topics Covered

- What Is a Threat Vector?
- What Is an Attack Surface?
- Common Threat Vectors
- Common Attack Surfaces
- Reducing the Attack Surface
- Best Practices
